# 🎬 AniVault

AniVault is a lightweight anime discovery single-page application built with React, Tailwind CSS, and Framer Motion. It fetches real-time data and official trailers via the Kitsu API.

## ✨ Features

* **Trending Anime:** Browse currently trending series.
* **Instant Search:** Live search with debounced API requests.
* **Trailer Modal:** Embeds YouTube trailers with mobile-friendly controls.
* **Smooth UI:** Scroll-triggered grid animations powered by Framer Motion.

## 🛠️ Tech Stack

* React + Vite
* Tailwind CSS
* Framer Motion
* Axios
* Kitsu API
